## Source and runtime boundaries

```text
public sieun-pi source
  ├─ extensions and skills -> explicit profile plan and apply
  ├─ utility exports      -> application dependency
  ├─ daily recap          -> generated external runtime
  └─ pool patch updater   -> two-file external runtime

private settings, accounts and histories -> remain outside public source
```

Package installation does not change the Prime profile.
Profile apply, runtime generation, dependency installation, bundle patching and service activation are separate actions.
A running process keeps its loaded code until native resource reload.
Rollback restores only receipt-owned targets that still match their applied state.
